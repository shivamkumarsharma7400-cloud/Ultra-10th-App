# 📱 Ultra 10th - Official Mobile App

The official mobile app companion for **Ultra 10th** (Class 10 Board Exam Prep platform). Built with Flutter & Material 3, designed for seamless test practice, chapter notes, NCERT solutions, and board exam resources.

---

## 🚀 Key Highlights

- **Package Name**: `com.ultra10th.app`
- **Target SDK**: Android 15 (API 35) | Min SDK: Android 5.0 (API 21)
- **Framework**: Flutter 3 (Material 3 Dark/Light sleek UI)
- **CI/CD Pipeline**: 100% automated cloud builds via GitHub Actions (no local Flutter SDK required)

---

## 🛠️ GitHub Actions Build & Release Workflow

Everything runs directly in GitHub Actions! You don't need Android Studio or Flutter installed locally.

### Step 1: Generate your Play Store Upload Keystore (One-time)

1. Open this repository on GitHub: [Ultra-10th-App](https://github.com/shivamkumarsharma7400-cloud/Ultra-10th-App)
2. Go to the **Actions** tab.
3. Click on **Generate Play Store Keystore** on the left menu.
4. Click **Run workflow**. (You can keep the defaults or enter your custom passwords).
5. Once finished:
   - Click the workflow run.
   - Look at the **Summary** tab — it will show you the exact values to save.
   - Download the `play-store-upload-keystore` artifact as a backup.

### Step 2: Add GitHub Secrets (One-time)

In your repository on GitHub:
Go to **Settings** > **Secrets and variables** > **Actions** > **New repository secret**:

| Secret Name | Description |
|---|---|
| `KEYSTORE_BASE64` | The complete Base64 encoded string generated by the workflow |
| `KEYSTORE_PASSWORD` | Password you set (e.g. `Ultra10thKey2026!`) |
| `KEY_PASSWORD` | Key password (same as keystore password) |
| `KEY_ALIAS` | Key alias (default: `ultra10th`) |

### Step 3: Automated Builds & Downloads

- Whenever you push code to `main`, GitHub Actions automatically builds:
  1. **Release APK (`Ultra-10th-v1.0.0-Release-APK`)**: Ready to install directly on phones.
  2. **Google Play Store AAB (`Ultra-10th-v1.0.0-PlayStore-AAB`)**: Ready to upload directly to Google Play Console.
- You can also run the **Build Ultra 10th App** workflow manually anytime from the **Actions** tab.
